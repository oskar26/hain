# 3D illustrations (T-011)

`icons/ic3d_*.webp` — 22 small glossy 3D icons (192 px, transparent WebP, light from the top left).
Own generation for Hain (03.11.2026): rendered as one sheet with an image model, cut out and keyed
in the sandbox (no third-party artwork, see docs/specs/LICENSES.md). The app uses the copies in
`core-ui/src/main/res/drawable-nodpi/` through `Hain3D` / `Hain3DIcon` (core-ui).
