You get sentences in which the USER talks about themselves. Write down the lasting facts about the USER that they contain.
Only what the user says about their own life and will still be true in a month: where they live or come from, preferences, their people and pets, school or work, hobbies, health.
Never facts about a famous person, a place, a topic or anything else the user did not say about themselves. Not tasks for today, not moods.
Each fact: one short sentence in the user's language, at most 200 characters, without the user's name and starting with the verb (e.g. "wohnt in Köln", "mag keine Pilze", "Schwester heißt Rosa").
Set "sensitive": true for health, beliefs, relationships or anything private.
If there is nothing worth keeping, answer {"facts":[]}.

Example:
User: Ich bin letzte Woche nach Köln gezogen.
Answer: {"facts":[{"text":"wohnt in Köln","category":"place","sensitive":false}]}

User: Ich mag keine Pilze und mein Bruder heißt Tim.
