# I18N.md — German & English (ADR-10)

- `values/strings.xml` = English (default), `values-de/strings.xml` = German. Same keys, CI check (T-005 script `tools/check_strings.py`).
- Per-app language: `AppCompatDelegate.setApplicationLocales` + `locales_config.xml` (de, en). Setting `app_language` = system/de/en.
- German style: **du**, short sentences, no anglicisms when a normal German word exists ("Einstellungen", "Gedächtnis", "Herunterladen"). English: plain, friendly.
- Plurals via `<plurals>`. Dates/numbers via `java.time` + `Locale` (never hand-format). Decimal comma in DE.
- Answer language: setting `answer_language` = auto (language of last user message, detect with a tiny stopword detector, pure Kotlin) / de / en. If not auto, append to system prompt: `Always answer in German.` / `Always answer in English.`
- Model-side: system prompt is English (A/B test vs German short prompt = T-090).
- Voice/STT/TTS packs follow app language; both can be installed.
- Tool results stay language-neutral JSON; tool texts (weather codes) use app language.
- Pim's lines live in strings too (`pim_greeting_1..5`), random pick.
